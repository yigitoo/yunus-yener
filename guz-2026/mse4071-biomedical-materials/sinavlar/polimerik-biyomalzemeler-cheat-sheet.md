## Tek bakışta
| Polimer | Hatırlanacak |
|---|---|
| UHMWPE | 3–6 M g/mol, aşınma dirençli, düşük sürtünme, kemiğe bağlanmaz (HA ile bioactive), γ-ışın = cross-link → eklem protezi |
| PLA | hydrophobic, yavaş hidroliz |
| PGA | hydrophilic, hızlı bozunur |
| PLGA | lactide/glycolide oranıyla ayarlanabilir bozunma → suture, graft, nanopartikül |
| PMMA | bone cement: fiksasyon var, osseointegration yok |
| PU | hard (diisocyanate) + soft (polyol); isocyanate toksik; vascular graft, catheter |
| Silicone (PDMS) | Si–O, Tg −120 °C, O₂ geçirgen; zayıf aşınma, protein adsorpsiyonu, fibrous encapsulation |
| Hydrogel | cross-linked hydrophilic, ~%90 su; diffusion / swelling / chemical release |
| PEEK | aromatik + kristalin, modulus kemiğe yakın; hydrophobic, bioinert → HA ile bulk modifikasyon |
| PTFE | non-stick, bakteri tutmaz → kalp kapakçığı |
| SMP | heating → deforming → cooling → reheating; stent, suture |

## Kavramlar
- **Tg:** yalnızca amorf/yarı kristalin. Altında sert-kırılgan, üstünde rubbery.
- **Hydrolysis:** ester/amide/anhydride bağları. **Surface erosion:** yüzeyden. **Bulk erosion:** tüm hacimde.
- **Etkileyen faktörler:** zincir uzunluğu, M_w, kristallik, dallanma, cross-link, katkı, yoğunluk, functional group, porosity.
- **Natural biopolymer:** polysaccharide (alginate, chitosan, hyaluronic acid, cellulose, gelatin), protein (collagen, silk fibroin).
- **Bone graft:** küçük defektte autologous graft en iyi; büyük defektte porous scaffold.
