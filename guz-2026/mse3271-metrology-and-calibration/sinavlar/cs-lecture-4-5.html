C

Variance ve standard deviation ★

Sezgi: Ortalama (μ, "mü") verinin merkezini, standart sapma (σ, "sigma") verinin merkezden tipik uzaklığını söyler. σ'yı bir adım uzunluğu gibi düşün. Farkların düz ortalaması hep 0 çıkar (artılar eksileri götürür) → önce kare alınır (varyans, birimi mm²), sonra karekök ile birim geri mm'ye döner (standart sapma).

Formül ve adımlar slayt 47–58

σ² = Σ(x − μ)² / N (variance, varyans) σ = √[ Σ(x − μ)² / N ] (standard deviation)
  1. Ortalamayı bul
  2. Her değerden ortalamayı çıkar (deviation)
  3. Farkların karesini al
  4. Kareleri topla
  5. N'ye böl → varyans · karekök → σ

σ küçük → veriler ortalamaya yakın (yüksek precision) · σ büyük → dağınık

Çözümlü örnek

Veri: 2, 4, 4, 4, 5, 5, 7, 9 N = 8 μ = 40 / 8 = 5 Farklar: −3, −1, −1, −1, 0, 0, 2, 4 Kareler: 9, 1, 1, 1, 0, 0, 4, 16 → Σ = 32 σ² = 32 / 8 = 4 σ = √4 = 2
Slayt N'ye bölüyor (popülasyon). Soruda "sample" geçerse n − 1'e böl (Lecture 2'deki Type A uncertainty'de de öyle).

Normal distribution (normal dağılım) ★

Özellikleri slayt 51–53, 57–70

  • Çan eğrisi (bell curve); uçlarda eksene yaklaşır ama değmez (asymptotic)
  • Ortalama etrafında simetrik; mean = median = mode
  • Eğri altındaki toplam alan = 1 (%100); alan = olasılık / oran
  • Sadece ortalama ve standart sapma bilinirse tamamen tanımlanır
  • Örnekler: insan boyu, makinelerin ürettiği parça ölçüleri, ölçüm hataları, kan basıncı, sınav notları

68 – 95 – 99.7 kuralı

μ ± 1σ → %68 of values μ ± 2σ → %95 μ ± 3σ → %99.7
Lecture 2 bağlantısı: expanded uncertainty'de k = 2 → %95 buradan gelir.

68 / 95 / 99.7 nereden geliyor?

Çan eğrisinin altındaki toplam alan = %100. Bir dilimin alanı = o aralıktaki değerlerin yüzdesi. Eğri ortada kalın, kenarlarda ince olduğundan alanın çoğu ortada toplanır. Sayılar z tablosundan gelir: tablo 0'dan z'ye (tek taraf) alanı verir, iki tarafa genişletmek için × 2.

Ters soru tipi: aralıktan ortalama ve σ bulma slayt 64–66, 99–104

Mean = (alt + üst) / 2 σ = (üst − alt) / (2 × kaç σ) %68 → /2 · %95 → /4 · %99.7 → /6 Ör 1: %95'i 1.1 – 1.7 m → mean = 1.4 m σ = 0.6/4 = 0.15 m 1.85 m'lik arkadaş → (1.85 − 1.4)/0.15 = 3σ uzakta (çok nadir) Ör 2: %99.7'si 1.176 – 1.224 cm → mean = 1.200 cm σ = 0.048/6 = 0.008 cm Ör 3: %95'i 62 – 90 kg → mean = 76 kg σ = 28/4 = 7 kg Ör 4: %68'i 51 – 64 puan → mean = 57.5 σ = 13/2 = 6.5

z-score ve z tablosu ★

Formül slayt 75–81

z = (x − μ) / σ (popülasyon) z = (x − x̄) / s (örneklem)
  • z = değerin ortalamadan kaç σ uzakta olduğu; işaret yönü verir (− altında, + üstünde)
  • z-score'lar: ortalama 0, σ = 1 olan standard normal distribution
  • Kullanım 1: farklı ölçekleri karşılaştırmak · Kullanım 2: tek tabloyla oran bulmak
IQ (μ=100, σ=15): 115 → z = +1 · 70 → z = −2 Fred: Test A 78 (μ=70, σ=8) → z = 1.00 Test B 78 (μ=66, σ=6) → z = 2.00 → B'de daha iyi

z tablosu nasıl okunur? slayt 82–87, 105–113

Tablo genelde 0 ile z arasındaki alanı verir. Satır = z'nin ilk ondalığı, sütun = ikinci ondalığı.

z0 → z arasız'nin ötesi

"z'nin ötesi" = 0.5 − (0→z) "z'den küçük" = 0.5 + (0→z) "−a ile +b arası" = (0→a) + (0→b) Ör: 0 → 0.45 = 0.1736 → %17.36 Ör: −1 → 2 = 0.3413 + 0.4772 = 0.8185 → %81.85

Klasik soru: 480 not, μ = 60, σ = 8. Kaç kişi 76 veya üstü aldı? slayt 81–83

① Çiz: 76 ortalamanın sağında ② z = (76 − 60) / 8 = 2.00 ③ Tablo: z = 2.00 ötesi = 0.0228 ④ Oran = 0.0228 → %2.28 → Kişi = 0.0228 × 480 = 10.94 ≈ 11 kişi

Tam örnek: terazi, 4 tartım (8, 10, 12, 10 g) → σ, z ve yorum

μ = 40 / 4 = 10 g farklar −2, 0, +2, 0 (toplam 0 ✔) kareler 4, 0, 4, 0 → Σ = 8 σ² = 8 / 4 = 2 g² σ = √2 = 1.41 g Yeni tartım 14 g: z = (14 − 10) / 1.41 = 2.83 ← paydada σ (1.41), varyans (2) DEĞİL %95 aralığı = 10 ± 2·1.41 = 7.17 – 12.83 g → 14 g dışarıda Tablo: z = 2.83 → 0.4977 → ötesi 0.5 − 0.4977 = 0.0023 (%0.23, 1000'de ~2)

Yorum: |z| < 2 normal · 2 < |z| < 3 şüpheli · |z| > 3 çok tuhaf. 14 g bir outlier (aykırı değer): ölçüm hatası veya cihaz sorunu olabilir, kontrol edilir.

⚠️ Sınav tuzakları

  • En sık hata: z formülünde ve μ ± kσ aralığında σ kullanılır, varyans (σ²) değil. Varyans 2 ise σ = √2 = 1.41.
  • Aralık sorusunda ortalama = (alt + üst) / 2, yüzde kaç olursa olsun (simetri). Ör: %68'i 51–64 → μ = 57.5, σ = 13/2 = 6.5.
  • Interval vs ratio: °C interval (sıfır keyfi), kelvin, boy, kilo, yaş ratio (gerçek sıfır). Oran yalnızca ratio'da anlamlı.
  • (ΣX)² ile ΣX² farklı: önce topla sonra kare ≠ önce kare sonra topla.
  • z tablosunda hangi alanın verildiğine bak: "0'dan z'ye" mi, "z'nin ötesi" mi?
  • %95 aralığından σ bulurken 4'e böl (2σ sağ + 2σ sol); %68'de 2'ye, %99.7'de 6'ya.
  • Normal dağılımda mean = median = mode; dağılım çarpıksa eşit değildir.
